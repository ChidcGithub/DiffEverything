## Remaining Boundaries

These are explicit scope choices, not CLI feature defects:

- The full enter/exit Dijkstra graph search from difftastic is not reproduced line by line. Tree mode uses content signatures, optimal bipartite matching and order-sliding normalization. Graph mode uses a bounded syntax-event graph shortest path + non-local exact move edges, depth-independent token equality, subtree grouping and LCS move detection (including a minimal-index-shift slider), with Myers fallback for very large nodes.
- Fonts support TTF/OTF/TTC/WOFF/WOFF2; WOFF2 is unpacked to SFNT through Brotli and table transforms, then compared using the same metadata path.
- nbdime's web rendering is not implemented. Notebook cells are globally aligned by id when present; cells without ids use signature-based move estimation.
- uni-diff's character/coordinate-level block-level visual localization inside documents is not fully reproduced. PDF has page-level text localization, and images/PDFs have coarse changed-region bounding boxes.
- OpenAPI breaking-change checks cover common operation/path/response/required-parameter rules; complex schema semantics are still rendered as a generic JSON tree.
- Pure-Rust HDIFF13 single-file and HDIFF19 directory encoding/apply are complete (directory encoding includes fadler64 checksums, same-file dedup, optional zstd/zlib/lzma2/bzip2 head/hdiff compression); the apply side reads official zstd-compressed heads and fadler64-checksummed directory patches.
- Regular HTML reports have no external resources; page images in PDF visual `report.html` are embedded as base64 PNGs.
- Unknown pickle globals are extracted as readable strings; corrupted pickles return a structured object with `$pickle_error` / `$bytes_hash` / `$readable_strings`.
