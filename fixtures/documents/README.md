# Document fixtures

- `old.odt` / `new.odt`, `old.odp` / `new.odp`: synthetic OpenDocument ZIPs
  with `content.xml`, `meta.xml`, `styles.xml` and embedded PNG entries.
- `old.epub` / `new.epub`: synthetic EPUB ZIPs with
  `META-INF/container.xml`, an OPF package and a chapter.
- `old.rtf` / `new.rtf`: hand-written RTF with paragraphs and formatting
  control words.
- `old.eml` / `new.eml`: MIME messages generated with Python's `email`
  package, including a text body and an attachment.
